# ZLX-ESP32-2 (C5) Example Code

This package splits the ZLX-ESP32-2 (C5) factory-test firmware into small standalone examples for learning, customization, and individual hardware verification.

## Folders

- `中文示例_CN/`: standalone PlatformIO examples with Chinese folder names
- `English_Examples_EN/`: standalone PlatformIO examples with English folder names
- `GPIO_Pinout_CN_EN.md`: bilingual GPIO reference

Each function folder is an independent project. Open the selected function folder directly in VS Code + PlatformIO instead of opening all examples as one project.

Included: ST7789 display, XPT2046 touch, TF card, audio/amplifier, 2.4/5GHz Wi-Fi, BLE, GT-U7 GPS/GNSS, GPIO26 green LED, battery ADC, and BOOT button.
